# Roadmap

## Key References

This plugin is a result of [Supernotify](https://supernotify.rhizomatics.org.uk) proposals [RFC-0004](https://supernotify.rhizomatics.org.uk/latest/developer/rfcs/0004-household_appliances_auto_notifier) and the more general [RFC-0003](https://supernotify.rhizomatics.org.uk/latest/developer/rfcs/0003-auto_notifier/).

The feedback from this first auto notify implementation is intended to be applied back to Supernotify itself, the proposal in [RFC-0005](https://supernotify.rhizomatics.org.uk/latest/developer/rfcs/0005-supernotify-tracked-notifications/)
